# README visual assets

- `cover.png`: generated with the built-in image-generation tool for this repository. Conceptual artwork, not a patient image or a results diagram. Copied into the project at `assets/readme/cover.png`.
- `dynamics.gif`: a scientific animation rendered with Matplotlib from `lab/dist/web_data.json`, example `0_combined`, on the included cortical display geometry. See `authoring/build_readme_animation.py`.
- `dynamics-preview.png`: still frame at 22 model seconds, provided as a static alternative to the animation.

## Cover generation prompt

Use case: stylized-concept. Create a premium editorial cover banner for the GitHub research project BBCI Adaptive Dynamics Lab. Very wide 3:1 landscape, intended 1536 by 512. Deep midnight navy background, restrained luminous teal and warm amber accents. On the right, an elegant abstract three-dimensional cortical silhouette formed from flowing layered contour ribbons and organized signal trajectories, fine engraved lines and subtle depth; sophisticated scientific art, not a photoreal patient scan. On the left, beautifully typeset, large and perfectly legible exact text: 'BBCI' in a small spaced label, then 'ADAPTIVE' and 'DYNAMICS LAB' on two lines, then smaller 'Measure. Adapt. Test.' Airy margins, commanding typography, beautiful quiet contrast, modern research institute visual identity. Flat full-bleed artwork suitable for embedding in a README, no browser frame, no UI buttons. Avoid puzzle pieces, medical crosses, robot heads, a glass brain on a pedestal, visual clutter, hype about cures, brand logos, watermark. Illustration is conceptual, not a scientific results diagram.
